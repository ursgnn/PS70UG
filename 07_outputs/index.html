Week 7: Outputs

Minimum Viable Product

For the MVP, I wanted to experiment with and figure out the mechanical side of my final project, but I mainly focused on circuit building. Before all of that, I thought it would be best to build my box first so I could store everything I was going to use inside it. The box design was taken from the internet, and it turned out pretty well.

Color Sensor

I bought a TCS3200 color sensor from Amazon and started building my circuit. I had no problems building the circuit on a breadboard, and the color sensor was working just fine until I accidentally burned it out. I had to buy a new one and repeat the process of calibrating the sensor, which easily took the most time. In the end, I was able to pull it off.

This was the replacement TCS3200 color sensor before I wired and calibrated it.

This was the circuit while I was testing the components across two breadboards.

This video shows the color-sensor calibration process.

Stepper Motor and Buzzer

After the color sensor was done, I started working on my stepper motor. I 3D printed different sizes of couplers and found one that fit perfectly with my stepper motor and lead screw. After I wired the motor, I also wanted to add a buzzer because it would enhance the project and be effortless and easy to implement (foreshadowing).





MVP Result

The last thing I did was make everything fit on one breadboard instead of using two. This would help when I started soldering everything onto the protoboard. At the end of the MVP process, I had a box, a working color sensor, an RGB light, a buzzer, a working website to control the circuit, and a working stepper motor with a coupler.

This video shows the color sensor, motor, buzzer, and website working together.
